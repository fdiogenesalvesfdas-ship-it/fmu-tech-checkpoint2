# FMU Tech Inovação - Checkpoint 2: Protótipo e Evolução

## 📌 1. Detalhes do Projeto
* **Problema:** A complexidade na gestão, normalização e cruzamento rápido de dados relacionais (clientes, produtos, pedidos e itens) em sistemas corporativos.
* **Solução:** Implementação de um banco de dados relacional estruturado em 3ª Forma Normal (3FN) utilizando SQLite no Visual Studio Code, garantindo integridade e consultas eficientes via `JOIN`.
* **Evolução desde o Checkpoint 1:** Evolução da modelagem conceitual inicial para um protótipo de banco de dados funcional e persistente, incorporando as diretrizes pedagógicas.

## 🛠️ 2. Tecnologias Utilizadas
* **Banco de Dados:** SQLite (`normalizacao.db`)
* **Linguagem:** SQL
* **Ambiente:** Visual Studio Code (VS Code) com extensão SQLite Explorer

## 🚀 3. Como Executar o Protótipo
1. Clone ou descarregue este repositório.
2. Abra a pasta do projeto no **Visual Studio Code**.
3. Certifique-se de ter a extensão **SQLite** instalada no VS Code.
4. Abra o arquivo `trabalhos_fmu.sql`.
5. Selecione o bloco de comandos, pressione `Ctrl + Shift + P`, digite `SQLite: Run Query` e prima `Enter` para ver os dados unidos no painel de resultados.
